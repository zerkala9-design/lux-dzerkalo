# Розгортання на хостинг (adm.tools) через GitHub

Сайт автоматично збирається й заливається на хостинг по FTP при кожному пуші
(GitHub Action: `.github/workflows/deploy.yml`).

## Одноразове налаштування

### 1. Дані FTP (у панелі adm.tools)
- Розділ **FTP → Користувачі FTP** → створіть користувача (або візьміть наявного).
- Запишіть: **сервер** (хост або IP `185.104.45.94`), **логін**, **пароль**.
- У **Мої сайти** подивіться **кореневу теку сайту** (document root), напр.
  `/lux-zerkalo.com.ua/www/` — знадобиться для `FTP_SERVER_DIR`.

### 2. Секрети в GitHub
Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**:
| Назва | Значення |
|---|---|
| `FTP_SERVER` | `185.104.45.94` (або `ftp.lux-zerkalo.com.ua`) |
| `FTP_USERNAME` | логін FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_SERVER_DIR` | корінь сайту, напр. `/lux-zerkalo.com.ua/www/` (з / на кінці) |

### 3. Запуск
- Після додавання секретів відкрийте вкладку **Actions** → workflow
  **«Build & Deploy to hosting (FTP)»** → **Run workflow** (або просто зробіть будь-який пуш).
- Сайт збереться й заллється у вказану теку.

## Подальші зміни
Будь-яка зміна в коді + push у GitHub → Action сам пересобирає й заливає на хостинг.
Нічого вручну завантажувати не треба.

## Перемикання домену (коли готові)
У панелі домену (Effect) змініть `A`-записи `@` і `www` на **185.104.45.94**.
Записи MX/TXT (пошта) не чіпати. Деталі — у розмові.
