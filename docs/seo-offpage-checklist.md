# Off-page SEO чек-ліст — Lux Dzerkalo

Контент на сайті вже сильний. Далі позиції (особливо топ-3/5 по комерційних і локальних
запитах) тягнуть **сигнали довіри поза сайтом** і **час**. Нижче — за пріоритетом впливу.

## 1. Google Business Profile (найбільший ефект для локальних запитів) 🔴
- [ ] Заповнити профіль на 100%: категорії (Виробник дзеркал, Скляна майстерня), опис, години, район обслуговування (Київ + область).
- [ ] Додати **20–30 реальних фото робіт** по напрямах (ванна, панно, спортзали, барбершоп, LED) + логотип, обкладинку.
- [ ] Регулярні **пости** (акції, нові роботи) — раз на 1–2 тижні.
- [ ] Збирати **відгуки** щотижня (посилання «залишити відгук» ми вже маємо на сайті) і **відповідати** на кожен.
- [ ] Заповнити «Товари/послуги» з посиланнями на відповідні сторінки сайту.

## 2. Локальні каталоги та довідники (NAP-цитування) 🔴
Скрізь — **однакові** назва, адреса, телефон (NAP), з посиланням на сайт:
- [ ] Kabanchik, Prom.ua (профіль компанії), OLX (бізнес-акаунт)
- [ ] 2GIS, Zakupka, Ua-region, Tiu.ua, Flagma, Deal.by/ua
- [ ] Місцеві каталоги «майстри Києва», «ремонт/меблі/скло»
- [ ] Google Maps (через GBP), Waze, Apple Maps

## 3. Соцмережі з посиланням на сайт 🟠
- [ ] Instagram (@dzerkala_kyiv): у шапці — лінк на сайт; у постах/reels — на конкретні статті (спортзали, панно).
- [ ] Facebook-сторінка: кнопка «Сайт», регулярні пости.
- [ ] TikTok/Reels з процесом виготовлення й монтажу (вірусний потенціал + трафік).
- [ ] Кожна нова робота = пост + лінк на відповідну сторінку/категорію.

## 4. Посилання (backlinks) 🟠
- [ ] **Партнерські**: студії/зали/барбершопи/салони, для яких робили дзеркала — попросити згадку з лінком («дзеркала — Lux Dzerkalo»).
- [ ] **Крафтові статті/кейси** на буд-порталах, дизайн-блогах (гостьові).
- [ ] Форуми та спільноти (ремонт, дизайн інтер'єру) — корисні відповіді з лінком там, де доречно.
- [ ] Дизайнери інтер'єрів — партнерство (вони рекомендують виробника).

## 5. Google Search Console — гігієна 🟢
- [ ] Після кожної нової/зміненої сторінки — «Перевірка URL» → «Запросити індексування».
- [ ] Стежити за звітом «Ефективність»: які запити ростуть у показах але без кліків → покращувати title/description саме тих сторінок.
- [ ] Стежити за «Індексування сторінок» — щоб нові статті потрапляли в індекс.
- [ ] Структуровані дані — тримати без помилок (Product, Article, FAQ, LocalBusiness, Review).

## 6. Поведінкові та конверсія (непрямо впливають) 🟢
- [ ] Реальні фото в кожній статті (робимо) — тримають користувача довше.
- [ ] Швидкість/мобільність (у нас ок) — не ламати.
- [ ] Чіткі CTA і телефон/Viber на видноті (є).
- [ ] Блок відгуків Google на сайті (є) — соціальний доказ.

## Реалістичні очікування
- Молодий домен: топ по комерційних запитах — це **місяці**, не тижні.
- Найшвидший приріст: **Google Business + відгуки + локальні каталоги** (локальна видача) —
  тут результат видно за кілька тижнів.
- Органіка по «дзеркала для …» дозріває поступово в міру накопичення посилань і довіри.

## Порядок дій (перші 2 тижні)
1. Довести Google Business Profile до 100% + 20+ фото.
2. Розмістити компанію в 8–10 каталогах з єдиним NAP.
3. Instagram/FB: лінк у шапці + 3–4 пости з посиланнями на статті.
4. Запросити 5–10 відгуків у задоволених клієнтів.
5. У GSC — запросити індексацію всіх нових сторінок.
