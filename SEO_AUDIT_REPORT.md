# SEO-аудит lux-zerkalo.com.ua

Дата: 2026-07-12 · Гілка: `seo-audit-fixes`

Технічний SEO-аудит статичного сайту (Astro 5, білінгва UK/RU) з подальшими безпечними
виправленнями. Жоден існуючий URL **не видалено і не змінено** — усі правки зворотні.

---

## Частина 1. Аудит (Кроки 1–5, тільки читання)

### Крок 1. Інвентаризація — ✅ здорово
- Astro 5.6.1, `@astrojs/sitemap` 3.3.0, `build.format: 'directory'` → усі URL із кінцевим слешем (консистентно).
- i18n: `uk` у корені, `ru` під `/ru/`, `prefixDefaultLocale: false`.
- `robots.txt`: `Allow: /` + `Sitemap: /sitemap-index.xml`.
- Контент: 35 статей UK, 76 статей RU; 10 товарів (×2 мови); 7 категорій.

### Крок 2. Sitemap ↔ маршрути — ✅ чисто
- До правок: **157 URL**, без `.html`, без сторінок з `noindex`.
- `xhtml:link hreflang` у sitemap додавалися лише для парних сторінок — коректно.

### Крок 3. Орфани та внутрішня перелінковка — ⚠️
- Справжніх орфанів немає (усі статті доступні зі списку `/statti/`, товари — зі сторінок категорій).
- Головна не лінкувала на грошові статті-пілари.
- 43 тонкі легасі-статті RU засмічували список `/statti/` і crawl budget.

### Крок 4. Meta / Schema — 🔴 знайдено баг
- Schema OK: LocalBusiness (усюди), Product+Offer, Article, BreadcrumbList, FAQPage.
- 🔴 **Перемикач мови у футері вів на 404**: він завжди лінкував на URL-двійника в іншій мові,
  навіть якщо той не існує. Постраждало **45 сторінок статей** (43 лише-RU + 2 лише-UK).
- ⚠️ hreflang у `<head>` було **вимкнено для всіх статей** (`alternates={false}`), тож навіть
  33 коректно-парні статті не мали звʼязку uk↔ru.

### Крок 5. Дублювання `/statti/` ↔ `/katalog/` — 🔴 головна проблема
- 43 легасі-статті RU, багато **ультратонких** (10–40 слів), дублювали одна одну та категорії
  (`зеркальная плитка / цена / на стену / на потолок / с фацетом …`) → канібалізація.
- Перетин *категорія спортзалів* ↔ *пілар «дзеркала для залів»* — навмисний hub/spoke, не проблема.

## Частина 2. Виправлення (Крок 6)

Обсяг узгоджено з власником: **A–C** + варіант **D4** (розширити 6 найцінніших легасі-статей,
решту вивести з індексу).

### A. Полагоджено перемикач мови у футері
`src/components/Footer.astro` — якщо у статті немає мовного двійника з тим самим slug, посилання
на іншу мову веде на список статей тієї мови (`/statti/` або `/ru/statti/`), а не на 404.
- лише-RU стаття → кнопка «UA» → `/statti/`;
- лише-UK стаття → кнопка «RU» → `/ru/statti/`;
- парна стаття → двійник (як і раніше).

### B. Увімкнено hreflang для парних статей
`src/components/pages/ArticlePage.astro` — `alternates` вмикається лише коли існує двійник із тим
самим slug (`articleHasTwin`). Тепер 33 парні статті отримали коректні `uk-UA` / `ru-RU` /
`x-default`, а статті без двійника не отримують зламаних альтернатив.

### C. Внутрішня перелінковка на грошові пілари
- `src/components/pages/HomePage.astro` — блок «Корисно знати» з 6 посиланнями на ключові статті
  (на замовлення, для залів, ванна, LED, фацет, плитка) + кнопка на весь блог.
- `src/components/pages/CategoryPage.astro` — на кожній категорії блок «Читайте також» із
  посиланням на профільну статтю (мапа `pillarMap`: vanna, led, facet, plitka, sportzal, interier).

### D4. Легасі-статті RU: розширено 6, решту (37) виведено з індексу
Розширено до повноцінних статей (унікальний контент, заголовки, CTA, внутрішні лінки):
1. `izgotovlenie-zerkalnoy-plitki` — «Изготовление зеркальной плитки на заказ»
2. `nestandartnie_zerkala` — «Нестандартные зеркала на заказ»
3. `obrabotka-stekla-_polirovka-stekla_-shlifovka-stekla_` — «Обработка стекла»
4. `steklo-lakobel` — «Стекло Lakobel»
5. `uzorchatoe-steklo` — «Узорчатое стекло»
6. `zerkalnaya-plitka-tsena` — «Цена зеркальной плитки за м²»

Решту 37 тонких дублів **виведено з індексу безпечно й зворотно** (URL лишається живим, 200):
- `src/data/noindex-articles.ts` — єдиний список slug-ів;
- `<meta name="robots" content="noindex, nofollow">` на цих сторінках;
- виключення з `sitemap` (`filter` у `astro.config.mjs`);
- виключення зі списку блогу `/statti/` та з блоку «інші статті».

Жодних 301 і видалень — обрано `noindex`, бо він не змінює структуру URL і повністю зворотний.

## Частина 4. hreflang та Schema (доповнення)

### hreflang — стан
Перевірка **живого** сайту показала, що hreflang **уже присутній** на всіх основних типах
сторінок (головна, категорії UA/RU, товари, послуги, галерея, контакти): двосторонній,
абсолютний, з `x-default` → UA. Коди — `uk-UA` / `ru-RU` (валідні, рішенням власника лишені без змін).

Приклад згенерованого `<head>` для пари головної:
```html
<!-- https://lux-zerkalo.com.ua/ (UA) та .../ru/ (RU) — однаковий набір -->
<link rel="alternate" hreflang="uk-UA" href="https://lux-zerkalo.com.ua/">
<link rel="alternate" hreflang="ru-RU" href="https://lux-zerkalo.com.ua/ru/">
<link rel="alternate" hreflang="x-default" href="https://lux-zerkalo.com.ua/">
```

Єдиний тип сторінок, де hreflang бракувало — **статті** (`ArticlePage` віддавав `alternates={false}`).
Виправлено в цьому ж PR (Частина 2, пункт B): для парних статей тепер генерується коректний
двосторонній набір `uk-UA` / `ru-RU` / `x-default`, для статей без двійника — не генерується
(щоб не вести на 404). Sitemap уже містить `xhtml:link` hreflang для парних сторінок (i18n увімкнено).

### Schema — доповнення
Аудит показав, що LocalBusiness (усі сторінки), BreadcrumbList (категорії), FAQPage (головна,
категорії), Product+Offer (товари) вже присутні. Єдина прогалина — **на сторінці товару не було
`BreadcrumbList`**. Додано `BreadcrumbList` (Головна → Каталог → категорія → товар) у
`src/components/pages/ProductPage.astro`.

## Рекомендації на майбутнє (необовʼязково)
- Розглянути 301 найтонших дублів на відповідну категорію (агресивніше за noindex, але змінює URL).
- Додати `lastmod` у sitemap через дати статей.
- Поступово нарощувати парні UK-версії для цінних RU-статей, які зараз лише-RU.
